<a id="cause-cold"></a>
**cold**: Process startup and runtime/HTTP initialization. Loader relocation and symbol lookup dominate the sparse cold profile. Trigger: empty revision-1 board, start the release binary and first selective GET. The 66-sample profile does not establish a complete decomposition.

<a id="cause-restart"></a>
**restart**: Generic JSON DOM construction (json_node/json_quoted/json_owned_text), SipHash/map probe and insertion, then derived conversion to typed Board and DOM destruction. Rust serde builds typed Items directly. Trigger: start over fixture(data, 10000) and first selective GET. Generic streaming typed deserialization remains open.

<a id="cause-list"></a>
**list**: Rendering and byte construction: memmove, alloc::grow, UTF-8 validation, append_byte_list, seq_grow and temporary f-string fragments. Explicit unique conversions remain in selection/rendering and final HTML-to-Bytes conversion; borrowed html.esc removes one source. Trigger: GET / over the 10k fixture. No app-specific change or per-subscriber board copy was introduced.

<a id="cause-search"></a>
**search**: Case-insensitive filtering plus all_tags construction and destruction of temporaries. Short-tag contains misses now reject before Two-Way preprocessing. Trigger: GET /?q=Task+9999 over the 10k fixture. Plain instructions meet 1.5x target.

<a id="cause-create"></a>
**create**: Direct derived JSON snapshot writing: byte appends, memcpy and dynamic-string escaping dominate. Field and variant names are now prequoted at compile time. Trigger: POST /tasks over the 10k fixture. Plain instructions meet 1.5x target; recording adds event hex formatting and flushes.

<a id="cause-update"></a>
**update**: Direct derived JSON snapshot writing: byte appends, memcpy and dynamic-string escaping dominate. Field and variant names are now prequoted at compile time. Trigger: POST /tasks/1/advance over the 10k fixture. Plain instructions meet 1.5x target; recording adds event hex formatting and flushes.

<a id="cause-sse"></a>
**sse**: Each subscriber scans/filter-renders its selected view; contains_ignore_case, all_tags and destruction dominate. Existing main no longer retains a full independent board per subscriber. Trigger: 1/100/1000 GET /updates with Task 9999 filter and one mutation. Plain instructions meet 1.5x target.

<a id="cause-heap"></a>
**heap**: Private ordinary heap dominates. Worker trimming and Linux slab-page discard reduce initial seeded RSS from 29.17 to about16 MiB (separate ten-round before/after session), still above2x Rust. Typed-board storage, runtime metadata, partially occupied slabs and non-slab libc retention remain; this combined startup/list/100-stream heap profile does not quantify their individual idle shares. Trigger: seed10k, GET /?q=Task+9999 and idle.


Minimal triggers use the fixture generated by `fixture(data, 10000)` and routes shown in each attribution. CPU profiles contain limited samples for short operations and incomplete unwinds across native fiber switches; flat symbol attribution is stronger than their full call chains. Causes identify measured mechanisms, not a percentage decomposition of every gap.

CPU and latency evidence comes from separate `perf record` runs; heap evidence is a separate heaptrack run over the same 10k seed and a full list render plus 100 SSE subscriptions. Neither profiling run contributes timing comparisons.
Low offered-rate cells have few requests: histogram tail values are empirical order statistics, not a claim of a production tail-latency bound. CPU15 busy samples are retained; time/cycle conclusions require an idle-sibling rerun when interference is present.
