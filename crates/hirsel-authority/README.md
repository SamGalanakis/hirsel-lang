# hirsel-authority

The authority, provenance and capture check: modes, brands, closures and capabilities
(docs/spec/ownership.md, brands.md, closures.md, capabilities.md and diagnostics.md).
[hirsel-modes](../hirsel-modes/README.md) documents it with the ownership check, under
"Authority, provenance and capture tables".

Allowed dependencies: hirsel-span, hirsel-syntax, hirsel-types, hirsel-diag, hirsel-intern,
hirsel-modes. The `testing` feature publishes `test_support`, the manufactured checked-body
fixtures hirsel-ownership's tests share.
