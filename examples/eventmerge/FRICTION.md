## Explicit ownership, wrapper and prefix recipes retained (about 4 minutes)

These were used from the first attempt, with no rejected alternate form:

- `EventKey` wraps `uuid.to_string(parsed_id)` as an opaque `key`; shipped
  `uuid.Uuid` is a transparent record. This protects canonical application
  identity without changing std or conflating version/variant with identity.
- Empty collections, the `Map[EventKey, u64]`, counters, error kind strings and
  byte builders carry explicit types/suffixes for prefix inference. No later
  statement supplies an earlier literal's type.
- `unique line` gives `json.parse` owned UTF-8 text; `unique payload` detaches the
  selected JSON member; `unique source` owns an error/event location.
  `copy event.id` admits the canonical key to the Map while retaining the event.
  `copy event.location` is sufficient for the owned local event; the borrowed
  previous location requires the deeper copy above.
- `invalid` centralizes typed error construction; explicit `match` arms preserve
  `JsonError`/`UuidError` in `Kind` while adding the source location. The report
  intentionally projects these causes to stable application error categories.
- `equal` recursively implements the declared equality: std keeps numeric
  lexemes and object insertion order; comparing serialized JSON would make
  reordered objects conflict. Its object lookups use the shipped borrowed
  `map.get` result. No shared helper or parser was added.
- Capability plumbing is limited to main: obtain one read-only Dir and stdout;
  pass Dir and branded File to bounded `bufio.file_read_more`. `process.ExitCode`
  lets errors use 1/2 while ordinary cleanup runs. The pure model has `uses {}`.

Disposition: documented application recipes and intentional rules. Additional
annotations/copies/wrappers/helpers are recorded here even when no diagnostic
was encountered. These observations cover this package's enumerated scenarios.
