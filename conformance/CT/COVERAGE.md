# Compile-time data evaluation and pending coverage

- **CT-1:** scalar and aggregate data constants, closed inline expressions, ordinary declared calls, arithmetic/conditional values, overflow/division/contract/fact failures and divergent evaluation have controls. Section 23 assigns CT-1 to evaluated failures and preserves static rule owners. Derive/body generation and the CRC example are cut from v1 (#5).
- **CT-2:** materialized and dependent constants have run witnesses. Closed frames reject outer runtime bindings and abstract type/size inputs while allowing internal bindings and ordinary calls. Resource, capability and callable graphs do not cross the v1 data-publication boundary.
- **CT-3:** record, variant and generic-instance shapes have run witnesses that print the field and payload inventories computed at compile time. `shape(T)` outside compile-time code, including a helper only comptime calls, is rejected beside its comptime twin; a shape token crossing the materialization boundary is CT-2 beside a materialized `ShapeInfo`. Eligibility is under GEN-3 (scalar, distinct, alias-of-collection rejections with record, single-variant and alias-of-record twins) and opacity under PROG-2 (dependency opaque rejection, transparent dependency twin, owner opaque run). Compile-time-only values (TypeShape, Body) are rejected in run-time code beside a compile-time-only definition that holds one, and a run witness keeps non-generic compile-time-only definitions out of native code.
- **CT-5:** a run witness generates a body whose type equals the declared header, beside a header mismatch (LANG-7 at the generator call). A generator's `Error` is CT-1 with its message as a note, beside an accepted generator; text that is not one function literal is CT-5 and a literal of another type is LANG-7, both located in the generated text, beside accepted twins (the second renames the parameter under a contract). A generated body writing a borrowed parameter is OWN-1 at its generated line, beside the `mut` header. Cross-module spelling: a short name for another package's type is LANG-4 in the generated text, beside a run witness that spells it from the shape. Determinism: a generator reading a declared parameter is CT-2, beside a constant argument, and a run witness gets one body from two declarations whose generator iterates a set. A generator needing its own declaration is CT-4 beside an acyclic chain, and a generic declaration is CT-2 beside a generic generator serving a non-generic one.
- **CT-4:** self-cycle and mutual-cycle rejections retain accepted acyclic controls. Divergence tests CT-1 budget exhaustion, but numeric below/at/above-budget tests await #7's constant and charge model.
